# MentorBGITU

Перенос Figma-дизайна в код. Стек: **React 18 + Vite + Tailwind CSS + react-router + lucide-react**.

## Запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:5173

## Сборка

```bash
npm run build
npm run preview
```

## Экраны (роуты)

| Путь          | Экран Figma         | Описание                                   |
|---------------|---------------------|--------------------------------------------|
| `/`           | Home                | Лендинг: hero, как работает, направления, наставники, отзывы |
| `/login`      | Auth                | Вход в аккаунт                             |
| `/register`   | Reg                 | Регистрация                               |
| `/profile`    | Profile             | Личный кабинет, статистика, ближайшая запись |
| `/mentors`    | Mentors / Modal / Success | Список менторов + модалка записи + экран успеха (по состоянию) |
| `/knowledge`  | Knowledge           | База знаний — ресурсы                      |

## Структура

```
src/
  components/   Navbar, Footer, Logo
  pages/        Home, Auth, Reg, Profile, Mentors, Knowledge
  data/         mentors.js — список менторов и направлений
  index.css     дизайн-токены (btn, field, card) и Tailwind
tailwind.config.js  цвета бренда (#0088ff), тени, радиусы
```

## Замечания

- **Изображения** (hero-иллюстрации, фото менторов) в макете — растровые ассеты.
  Из-за лимитов экспорта они заменены на плейсхолдеры (градиентные блоки,
  аватары-инициалы, emoji). Замените на реальные файлы из Figma при необходимости.
- Иконки — `lucide-react` (соответствуют Feather-иконкам макета).
- Модалка записи и экран успеха реализованы как состояния страницы `/mentors`.
- В проекте также присутствует `main.py` (бэкенд PyCharm) — фронтенд лежит рядом
  и не конфликтует с ним.
